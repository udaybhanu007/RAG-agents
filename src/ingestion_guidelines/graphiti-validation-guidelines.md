## Guidelines

1. Ensure that Graphiti framework does entity & relationship extraction precisely based on the source documents present in Azure blob store.
2. Ensure that as per Graphiti framework functionality, entity extraction, schema evolution, relationship discovery, and temporal management from source documents should provide best performance.
3. Ensure that Graphiti framework should perform ingestion in Neo4j knowledge graph database using batch mode and the latency should be minimum. The performance of overall ingestion process should be monitored.
